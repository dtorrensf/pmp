pmp - Project Management Program

Usage: pmp [OPTIONS] [COMMAND]

Options:
  -h, --help       Print help information
  -v, --version    Print version information

Commands:
  mcp              Start the MCP server
  (no command)     Start the interactive TUI (default)

Environment:
  NO_COLOR         Disable colors (set to any non-empty value)
  PMP_THEME        Palette to use: default, bright
  PMP_ASCII        Use the ASCII glyph set (set to any non-empty value)
