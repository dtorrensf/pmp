pmp - Project Management Program

Usage: pmp [OPTIONS] [COMMAND]

Options:
  -h, --help       Print help information
  -v, --version    Print version information

Commands:
  mcp              Start the MCP server
  (no command)     Start the interactive TUI (default)

Configuration:
  ~/.config/pmp/config.toml   Theme, timeouts, logging and agent profiles
  ~/.config/pmp/theme.toml    Legacy palette file (still honored)

Environment (wins over the files):
  NO_COLOR         Disable colors (set to any non-empty value)
  PMP_THEME        Palette to use: default, bright
  PMP_ASCII        Use the ASCII glyph set (set to any non-empty value)
  PMP_REDUCED_MOTION  Turn off animations (set to any value other than 0)
  PMP_DB_*            SQLite lock policy (busy timeout, retries)
  PMP_MCP_TIMEOUT_SECS  Deadline for one MCP repository operation
